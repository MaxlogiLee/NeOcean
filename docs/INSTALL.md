# NeOcean Installation Guide

## System Requirements

- **OS**: Linux (tested on Ubuntu 20.04/22.04, CentOS 7/8)
- **Memory**: ≥ 128 GB RAM recommended (TEProf2 and STAR are memory-intensive)
- **Storage**: ≥ 500 GB free space per sample (including intermediate files)
- **CPU**: ≥ 20 cores recommended

## Step 1: Install Base Dependencies

### Conda / Mamba

Install Miniconda or Mambaforge if not already available:

```bash
# Miniconda
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh

# Or Mambaforge (faster)
wget https://github.com/conda-forge/miniforge/releases/latest/download/Mambaforge-Linux-x86_64.sh
bash Mambaforge-Linux-x86_64.sh
```

### Required System Tools

Install via conda or system package manager:

```bash
# Core bioinformatics tools
conda install -c bioconda star stringtie samtools bedtools gffread seqkit

# Parallel processing
conda install -c conda-forge parallel

# Python dependencies
conda install -c conda-forge pyyaml

# Perl modules (for SOAPfuse)
cpanm Parallel::ForkManager
```

## Step 2: Create Conda Environments

NeOcean uses the following conda environments (names preserved from original implementation):

### 1. teprof2

```bash
conda create -n teprof2 python=2.7 r-base=4.1
conda activate teprof2
conda install -c bioconda bedtools
# Install additional R packages as needed by TEProf2 scripts
```

### 2. cufflinks_env

```bash
conda create -n cufflinks_env -c bioconda cufflinks gffread
```

### 3. de_nove (EMBOSS for getorf)

```bash
conda create -n de_nove -c bioconda emboss
```

### 4. telocal-xly

```bash
conda create -n telocal-xly -c bioconda telocal
```

## Step 3: Prepare Reference Data

Create a reference data directory structure:

```bash
export NEOCEAN_RESOURCE_DIR="/path/to/neocean_resources"
mkdir -p ${NEOCEAN_RESOURCE_DIR}/{Reference,TEprof2,SOAPfuse,iREAD,Grep}
```

### 3.1 Reference Genome

```bash
# Download GRCh38 primary assembly
wget https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_42/GRCh38.primary_assembly.genome.fa.gz
gunzip GRCh38.primary_assembly.genome.fa.gz
mv GRCh38.primary_assembly.genome.fa ${NEOCEAN_RESOURCE_DIR}/Reference/

# Download GENCODE v42 annotation
wget https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_42/gencode.v42.primary_assembly.annotation.gtf.gz
gunzip gencode.v42.primary_assembly.annotation.gtf.gz
mv gencode.v42.primary_assembly.annotation.gtf ${NEOCEAN_RESOURCE_DIR}/Reference/

# Also get the basic annotation for TElocal
wget https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_42/gencode.v42.annotation.gtf.gz
gunzip gencode.v42.annotation.gtf.gz
mv gencode.v42.annotation.gtf ${NEOCEAN_RESOURCE_DIR}/Reference/
```

### 3.2 STAR Index

```bash
STAR --runMode genomeGenerate \
    --runThreadN 20 \
    --genomeDir ${NEOCEAN_RESOURCE_DIR}/Reference/STAR_index \
    --genomeFastaFiles ${NEOCEAN_RESOURCE_DIR}/Reference/GRCh38.primary_assembly.genome.fa \
    --sjdbGTFfile ${NEOCEAN_RESOURCE_DIR}/Reference/gencode.v42.primary_assembly.annotation.gtf \
    --sjdbOverhang 149  # read_length - 1
```

### 3.3 TElocal Index

Download or build the TE index (`GRCh38_GENCODE_rmsk_TE.gtf.locInd`) and its `.locations` file. Place in:

```
${NEOCEAN_RESOURCE_DIR}/Reference/
```

### 3.4 iREAD Resources

Place the `iread-master` directory and `intron_human_3877.bed` in:

```
${NEOCEAN_RESOURCE_DIR}/iREAD/
```

### 3.5 SOAPfuse Resources

Install SOAPfuse v1.27 and build its database. See SOAPfuse documentation for details.

```
${NEOCEAN_RESOURCE_DIR}/SOAPfuse/
```

### 3.6 Peptide Screening Databases

```bash
# UniProt human proteome
wget https://ftp.uniprot.org/pub/databases/uniprot/current_release/knowledgebase/reference_proteomes/Eukaryota/UP000005640_9606.fasta.gz
gunzip UP000005640_9606.fasta.gz
mv UP000005640_9606.fasta ${NEOCEAN_RESOURCE_DIR}/Grep/Uniport/uniprot_protein.fa

# NCBI RefSeq (optional)
mkdir -p ${NEOCEAN_RESOURCE_DIR}/Grep/NCBI
# Place ncbi_protein.fa here

# BN database will be generated by Module 08
```

## Step 5: Configure NeOcean

```bash
cd /path/to/neocean
cp config/config.template.yaml config/config.yaml
cp config/sample.template.yaml config/samples/MCJ.yaml
```

Edit `config/config.yaml` to set:
- `neocean.root_dir` — Path to this repository
- `neocean.resource_dir` — Path to `${NEOCEAN_RESOURCE_DIR}`
- All reference file paths

Edit `config/samples/MCJ.yaml` to set:
- `sample.name`
- `sample.work_dir`
- RNA-seq FASTQ paths
- (Optional) DNA BAM paths and HLA typing

## Step 6: Verify Installation

```bash
# Test YAML parsing
python3 -c "import yaml; print('PyYAML OK')"

# Test main script dry-run
bash workflow/main.sh \
    --global-config config/config.yaml \
    --sample-config config/samples/MCJ.yaml \
    --dry-run

# Check specific tools
STAR --version
stringtie --version
samtools --version
bedtools --version
```

## Troubleshooting

### PyYAML not installed
```bash
pip install pyyaml
# or
conda install pyyaml
```

### Conda environment not found
Ensure environment names in `config/config.yaml` match your installed environments:
```yaml
conda_envs:
  teprof2: "teprof2"
  cufflinks: "cufflinks_env"
  denovo: "de_nove"
  telocal: "telocal-xly"
```

### Permission denied on scripts
```bash
chmod +x workflow/*.sh modules/*.sh
```
